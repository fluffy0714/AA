# АА — Агрегатор Агрегаторов

Первый работающий прототип: одна корзина, сравнение её полной стоимости в
демомоделях Яндекс Еды и Купера, доставка, сборы, промокод и проблемные сценарии.

**Все товары, цены и правила вымышлены. Реальные API и оформление не подключены.**

## Запуск на Windows, macOS или Linux

Нужен Node.js 22 или новее. Runtime-зависимостей нет, `npm install` не требуется.

```sh
npm start
```

Открыть `http://localhost:3000`. Для разработки с перезапуском сервера: `npm run dev`.
`PORT` меняет порт, `HOST` меняет интерфейс (по умолчанию `127.0.0.1`).

Попробуйте кнопку «Попробовать с примером», промокод `DEMO10`, другие районы
и сценарии внизу страницы. «Сравнить подробно» показывает каждую статью расходов.
Оформление отключено; корзина хранится только в памяти открытой страницы.

## Проверки и переносимая сборка

```sh
npm test
npm run build
```

`dist/` — статический демонстрационный сайт с тем же расчётным движком.
Его нужно раздавать через HTTP, а не открывать через `file://` (ES modules).
Например: `python -m http.server 8080 --directory dist`.
В статической версии нет серверного API; все данные и вычисления демонстрационные.

## API

- `GET /api/health` — состояние и `mode: demo`.
- `GET /api/catalog` — 12 демотоваров и три условных района.
- `POST /api/compare` — валидируемая корзина и расчёты двух демоадаптеров.
- `POST /api/checkout` — `501 INTEGRATION_NOT_CONNECTED`; заказ не создаётся.

Контракты и дальнейший план: [architecture.md](docs/architecture.md).
Исследование официальных источников: [integration-research](docs/integration-research/2026-10-22.md).

динамического адресного тарифа агрегаторов, переноса корзины или оплаты.
