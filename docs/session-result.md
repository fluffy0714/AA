## Проверено

- 25 автоматических тестов домена и HTTP API: полные суммы, доставка, сборы,
  пороги и лимиты скидки, неполные корзины, сбой провайдера, истечение расчёта,
  равная цена, валидация, отсутствие доверия к цене из браузера, запрет checkout.
- Chromium: поиск, категории, количество, пример корзины, применение промокода,
  смена победителя, таблица сравнения, недоступный товар, отказ сервиса, очистка.
- На ширине 390 px нет горизонтальной прокрутки страницы. Диалог сравнения
  помещается в экран. Проверка выполнена в браузерной эмуляции, не на устройстве.
- Обновление страницы очищает корзину; JavaScript-ошибок в smoke-сценарии нет.
- Серверная и статическая версии прошли один сценарий браузерной проверки.
- `npm run build` создаёт переносимую сборку без сторонних runtime-зависимостей.
- Публикация Sites завершилась статусом `succeeded`.

Опциональная браузерная проверка: `tests/browser-smoke.mjs`. Для неё нужен
Playwright с Chromium. `PLAYWRIGHT_MODULE` может указать путь к модулю,
`BROWSER_PATH` — путь к Chromium, `AA_BASE_URL` — адрес работающего приложения.
Скриншоты сохраняются в игнорируемую папку `artifacts/`.

## Как посмотреть и продолжить

Откройте демо, нажмите «Попробовать с примером», примените `DEMO10`, затем
переключите сценарии внизу страницы. Локальная разработка: `npm start`.
Работу можно отменить возвратом к исходной ветке; опубликованное демо управляется
отдельно через Sites. Переключение Git-ветки само по себе не меняет публикацию.
