# Купер: первая проверка официального доступа

Реализован отдельный клиент **только для чтения** списка магазинов:
`providers/kuper/fulfillment-client.js`. Он не подключён к демокаталогу,
не получает потребительскую корзину и не создаёт заказы.

Основание: [официальный Fulfillment API](https://docs.kuper.ru/api-products/fulfillment/swagger),
раздел «Получить список магазинов», проверен 22 октября 2026:

- `GET /api/fulfillment/v1/stores`;
- заголовок `Client-Token`;
- query `max_page_size` от 1 до 1000 и `page_token`;
- массив магазинов в `data`, пагинация через `next_page_token`;
- sandbox: `https://api-gw.k-stage.sbermarket.tech`;
- production: `https://api.kuper.ru`;
- для sandbox документированы заголовки
  `sbm-forward-feature-version-paas-content-fulfilment-api: integrations`
  и `sbm-forward-tenant: sbermarket`.

Список ограничен магазинами API-клиента. Это **не доказательство доступа ко всему
ассортименту Купера**. Спецификация Client apps API и сценарий передачи готовой
корзины по-прежнему требуют ответа партнёра.

## Как проверить после получения ключа

Нужны выданный Купером `Client-Token` и подтверждение, для какой среды он действует.
Передайте его через менеджер секретов или переменную среды `KUPER_CLIENT_TOKEN`.
Не добавляйте ключ в исходники, browser storage, публичные настройки или URL.

```sh
npm run kuper:check
```

По умолчанию выбирается sandbox. `KUPER_ENVIRONMENT=production` переключает
документированный production endpoint, когда такой доступ выдан партнёром.

Команда запрашивает одну запись и выводит только число записей и наличие
следующей страницы. Адреса, телефоны, ключ и токен пагинации не выводятся.
Клиент не следует HTTP-редиректам и ограничивает длительность запроса.
Ошибки доступа, лимита, сети и формата ответа различаются; тела ошибок не логируются.

## Что проверено

Тесты используют подставной HTTP-транспорт и вымышленные ответы по форме
документации. Проверены маршрут, параметры, заголовки, пагинация, отказ без ключа,
таймаут, обработка 401/403/429/500 и отсутствие токена в ошибках.

**Живой запрос не выполнялся: выданного ключа в сессии нет.** Совместимость с
актуальным sandbox и права проекта ещё не подтверждены. Получение магазинов
не заменяет интеграцию цен, наличия, полного quote, скидок и checkout.
